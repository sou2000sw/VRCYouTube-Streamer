【概要】
本ソフトは、YouTubeの動画やプレイリストを自分専用のHLSライブストリームに変換し、VRChat内の各種ワールドプレイヤー（iwaSync3, YPlay, ProTV等）でシームレスに再生するためのツールです。
通常のGUI操作に加え、外部アプリからHTTP JSON API経由で操作可能な「ヘッドレス（APIサーバー）モード」も搭載しています。

==================================================
🎮 【GUI操作と主な機能】
==================================================
1. キューのドラッグ＆ドロップ並び替え:
   各動画の「☰」マークまたはタイトルをドラッグして、直感的に順番を入れ替えられます（リストの上下端に持っていくと自動スクロールします）。従来の「▲」「▼」ボタンによる並び替えも併用可能です。

2. シャッフル再生 & キュー保持ループ再生:
   - [🔀 Shuffle List] : 現在のキューを一瞬でランダム順に並べ替えます。
   - [🔀 Shuffle] スイッチ : キューから次に再生する動画をランダムに選んで再生します。
   - [🔁 Loop] スイッチ : 再生が終了した動画をキューの末尾に自動再登録し、同じリストをエンドレスにループ再生します。

3. ⚙ Settings（設定画面）:
   画面右上の「⚙ Settings」ボタンから、以下の設定を変更・保存できます：
   - サーバーポート (デフォルト: 8000)
   - HLSセグメント/バッファリング秒数 (デフォルト: 3秒)
   - 動画切り替わり時のバッファ待機秒数 (デフォルト: 5秒)
   - Web Player 再生同期バッファ数 (デフォルト: 4)
   - 起動時の Loop / Shuffle デフォルト有効設定
   ※ 設定ダイアログ内の「▶ API 仕様・引数リファレンス」をクリックすると、外部連携用のAPI一覧を展開・確認できます。

4. 📱 スマホ共有用 QRコード & Webリクエスト機能:
   - 待機画面（Standby）: キューが空になると、VRChat内の画面に「QRコード ＆ WebリクエストURL」が描画された待機映像がループ配信されます。
   - スマホからの動画追加: ワールド内のプレイヤーがスマホカメラでQRコードを読み取るとWebリモコン画面が開き、YouTube URLを貼り付けて「キューに追加」を押すだけで自動再生されます。
   - [📱 QR Code] ボタン : アプリ画面上のボタンからいつでもQRコードウィンドウを開いて提示・共有できます。

5. 🛡️ セキュリティ機能（多層防御）:
   - 外部からのアクセス時、アプリ終了・設定変更・キュー消去等の管理操作は自動遮断（403 Forbidden）され、動画追加のみ安全に許可されます（SSRF・ローカルファイル保護、連投制限付き）。

6. 🌐 Web Player / Web リモコン画面:
   ブラウザで「 http://localhost:8000/ 」（またはトンネル公開URL）にアクセスすると、配信のプレビュー再生、キューのリアルタイム閲覧、動画の追加が可能です。

==================================================
🤖 【ヘッドレス・APIサーバーモード (外部アプリ連携)】
==================================================
コマンドラインから以下のように起動することで、GUIを表示せずバックグラウンドのAPIサーバーとして動作します：

  VRC_Media_Streamer.exe --headless --port 8080

【主なAPIエンドポイント (JSON / CORS対応)】:
- GET  /api/status   : ストリーマーの状態、URL、再生中動画、キュー一覧の取得
- POST /api/queue    : キューへの動画URL追加 ({"url": "https://..."})
- POST /api/control  : 再生制御 ({"action": "skip" / "clear_queue" / "stop" / "shuffle" / "set_loop" / "set_shuffle"})
- POST /api/shutdown : サーバーおよびプロセスの安全終了
- GET  /api/config   : 現在の設定値の取得
- POST /api/config   : 設定値の更新・保存

==================================================
⚠️ 【重要：VRChat内での設定について】
==================================================
VRChat内で本ツールの配信（*.trycloudflare.com）を読み込ませるには、VRChatのメニューから以下の設定を有効にする必要があります。この設定がオフの場合、動画が再生されません。

設定箇所: Settings ＞ Downloads & Share
設定項目: Allow Untrusted URLs（信頼できないURLの許可）をオンにする

💻 【動作環境・必要なもの】
対応OS: Windows 10 / 11 (64bit)
ネットワーク: 安定したインターネット接続環境（アップロード帯域を使用します）
VRChatプレイヤー: iwaSync3, Yacc, KineLister, ProTVなど、HLSストリーム（.m3u8）に対応したワールドプレイヤー

ℹ️ 【製品の仕様・制限事項】
- URLの再生成について: Cloudflareの一時トンネル技術を使用しているため、本ツールを再起動するたびにVRChatに入力するストリームURLが変わります。起動中はずっと同じURLでご利用いただけます。
- YouTubeの仕様変更について: YouTube側の仕様変更により、動画の取得やプレイリストの展開が一時的にできなくなる場合があります。

⚖️ 【ライセンス表記（FFmpegについて）】
本パッケージには、動画変換処理を行う外部ツールとして FFmpeg（GPL/LGPLライセンス）の実行ファイル（ffmpeg.exe）が同梱されています。
本アプリはFFmpegのバイナリを改変せず外部プロセスとして呼び出しています。
FFmpegのソースコードは、公式サイト（ https://ffmpeg.org ）より入手可能です。
